# CampusShop

## Descripción
CampusShop es una tienda en línea desarrollada con HTML y CSS modular.  
Incluye todas las vistas principales: Home, Catálogo, Producto, Carrito, Checkout, Perfil, Historial y Pantalla Vacía/Error.  
El diseño es responsive y sigue una estructura clara de carpetas.

## Estructura de carpetas

CampusShop/
│
├── index.html          # Página principal (Home)
├── catalogo.html       # Catálogo de productos
├── producto.html       # Detalle de producto
├── carrito.html        # Carrito de compras
├── checkout.html       # Proceso de pago
├── perfil.html         # Perfil del usuario
├── historial.html      # Historial de pedidos
├── vacio.html          # Pantalla vacía / error
│
├── IMAGENES/           # Carpeta de imágenes
│
├── css/
│   ├── base.css        # Estilos globales
│   ├── layout.css      # Estructura general
│   ├── components/     # Estilos de componentes
│   └── responsive/     # Media queries

Código

## Cómo usar
1. Abrir `index.html` en el navegador para ver la página principal.  
2. Navegar entre las vistas usando los enlaces o el icono del carrito.  
3. El diseño se adapta automáticamente a celular, tablet y computador.  

## Características
- Home con barra de búsqueda, categorías y productos destacados.  
- Catálogo con grid responsive y etiquetas de oferta/stock.  
- Producto con imagen grande, descripción y botón de compra.  
- Carrito fijo en la esquina, con resumen de compra.  
- Checkout con formularios ordenados.  
- Perfil con datos y enlaces.  
- Historial con pedidos anteriores.  
- Pantalla vacía para estados sin contenido.  

## Notas
- Las imágenes deben estar en la carpeta `IMAGENES/`.  
- Los estilos están separados en módulos para mantener orden y claridad.  
- El proyecto es estático, no tiene backend ni base de datos.
